主题商店

一份 JSON，
整个 App 跟着换装。

主题不只是换个颜色——它是可以导入导出的主题包文件。点下面任意一套，这个页面会立刻跟着换装。

{
  "format": "shiguangji-theme-pack",
  "version": 1,
  "name": "拾光暖阳",
  "author": "拾光记官方",
  "colors": {
    "paper": "#FAF5EE",
    "brand": "#C4663F",
    "ink": "#33291F"
  }
}

主题包的移植性：每套主题就是上面这样一份 JSON 文件，存在应用的 themes/ 目录下，启动时自动识别加载；缺少的字段自动回退默认值，不怕文件缺斤少两。导出后可以发给朋友，也可以在自己多台设备间同步——换手机，主题跟着走。
